# Support

- **Question or problem:** read the [README](README.md) first, mainly "Troubleshooting" and "Limits".
- **Bug:** open an issue with the bug form: <https://github.com/codeFi/clauds/issues/new/choose>.
- **Idea:** open an issue with the feature form.
- **Security problem:** read [SECURITY.md](SECURITY.md). Do not open a public issue.

This is a free project that one person maintains in spare time. Answers can take some days.

Clauds is not made by Anthropic. For problems with the Claude app or your Claude account,
contact Anthropic support.
